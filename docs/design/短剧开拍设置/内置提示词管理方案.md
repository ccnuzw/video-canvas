# 短剧内置提示词管理

> 仅针对短剧开拍设置和项目设置的六类提示词；不改动个人提示词库、技能管理、模型或计费配置。请求字段和上线开关见 [开拍设置接口契约](接口契约.md#内置提示词运营目录)。

## 1. 目标与默认规则

管理员可以不发版就维护同一分类下的多套内置提示词；创作者可以不做任何额外选择就开拍，也可以逐类选择其他内置版本，或继续使用自己的提示词和原有技能。

| 分类 | 业务键 | 可维护的正文 |
| --- | --- | --- |
| 分集规划 | `plan` | `plan` |
| 分集剧本 | `scripts` | `scripts` |
| 资产拆解 | `assets` | `breakdown` |
| 资产图提示词 | `asset_prompts` | `asset_prompts` |
| 视频提示词 | `video` | `storyboard`，生成视频用的分镜文本，不是宫格图片 |
| 故事板提示词 | `board` | `board`，用于拼接宫格图片提示词 |

- 六类固定，每类可有多条，**必须且只能有一条已启用的默认项**。当前默认项不能直接停用或归档，必须先把另一条已启用的模板设为默认。每类独立设置，换默认不会动其他分类。
- **默认项用于新项目和主动选择默认的环节，不强推给旧项目。** 保存项目时锁定所选模板的正文版本；已建项目即使之后再发起任务，也沿用保存的正文，直到用户主动更换或更新该环节。已提交任务不受后续变更影响。
- 下架仅阻止新选用，不阻止已保存的项目继续生成。第一版只做软归档，不提供物理删除、全量历史版本管理或项目批量升级。

## 2. 管理后台

入口建议放在 **管理后台 → AI 配置 → 短剧提示词**，与「技能」并列、独立管理。

- **列表**：顶部切换六个分类；表格展示名称、用途、状态、更新时间和操作者，默认项置顶并标「默认」。可按状态筛选；编辑、设为默认、启停、归档放在行操作。空的筛选结果提示调整筛选，不暗示该分类无可用默认。
- **编辑**：复用后台现有表格和编辑面板样式。字段为名称、用途说明、正文和状态；分类在创建时选定，保存后不可跨类移动。支持从现有模板复制为停用项；复制时不继承默认。固定输入变量、输出 Schema 和格式化提示只读或不暴露，不通用化为「系统提示词管理」。
- **上线与恢复**：新建默认停用；保存正文、启用、设为默认是不同动作。对启用项直接保存正文会更新新选择可用的版本，保存前明确影响范围；切换默认前展示旧项 → 新项。建议先复制、校验再启用；紧急时可从随迁移保留的原版正文创建新的恢复项并设为默认。
- **校验与审计**：服务端校验分类、同类名称（归档项除外）、非空正文、长度与该环节规则；故事板复用现有占位符校验，必须保留 `{{画面}}`。记录创建、编辑、启停、切默认和归档的操作者、分类、模板 ID 及变更前后版本或状态。校验通过不代表模型效果通过，第一版不做后台调用模型试跑。

## 3. 创作者怎么选

延续截图中的六行胶囊，不加额外入口。打开分集规划的胶囊，示意如下（名称非预置清单）：

```text
分集规划   [标准分集 · 默认 ▾]
           内置提示词
           ✓ 标准分集       默认
             快节奏反转     更早安排冲突和集尾悬念
           我的提示词
             我的分集方案
             ＋ 新建提示词
           技能（沿用原有分类规则）
```

- 开拍设置与项目设置共用选择器；默认项置顶、其余按稳定顺序展示。选中后胶囊显示实际名称，不再一律显示「内置」。保持现有「我的提示词」新建、编辑和选择流程；新建个人提示词仍以当前分类的默认正文起草，保存后是独立副本。剧本型项目的分集规划、分集剧本仍置灰；故事板仍不显示技能。
- 「默认」标签只标当前默认。项目已选项如果后来下架，显示「已下架 · 仍沿用」；详情还能显示已保存的名称，不能再从候选中选到。若模板仍启用但正文改过，提供显式「更新至当前版本」，仅打开项目设置或保存其他字段不会隐式升级。
- 开拍界面加载目录失败时给出重试，不用硬编码正文冒充当前默认；已有项目仍可查看已保存的选择、提交原有生成链路或修改与提示词无关的设置。模板在打开弹窗后被停用或正文版本变动，提交时提示刷新并重新确认该环节，保留其他表单内容，不静默换词。仅默认标记变化、原选项仍启用且版本未改时，允许用户保留已看到的选择；重新打开的开拍界面预选新默认。

## 4. 数据与生成链路

### 后台与目录

- 数据建议拆为分类配置（固定分类键、`default_preset_id`、修订号）与模板（稳定 ID、分类、名称、用途、正文、启用/停用/归档、修订号、更新人和时间）。分类的默认指针非空，数据库用分类和模板 ID 的组合外键防止跨类指向；同类所有影响默认或候选状态的写操作按分类行加锁，在事务内检查指针指向已启用项。没有需要维护的第二份「是否默认」字段。
- 模板编辑按模板修订号、默认切换按分类修订号做乐观锁；过期请求返回冲突并刷新，不覆盖另一位管理员的修改。设置默认、停用、归档共用同一事务规则，避免两个管理员并发操作导致没有默认。默认切换重复提交若目标已达成可直接返回当前状态。
- 后台读写放在管理员授权路由（建议 `/admin/drama-prompt-presets`）。短剧端新增只读目录（建议 `GET /drama-prompt-presets`），一次返回六类、默认 ID，以及可选项的 ID、名称、用途、修订号，不批量下发正文。保留 `GET /drama-prompt-templates` 的结构和用途，改为给个人编辑器提供各类当前默认的可编辑正文，不返回协议层。

### 项目、任务与兼容

- 建剧和变更项目继续走现有接口。建议新增明确的模板选择类型 `source: "preset"`，提交 `id` 和 `revision`；服务端校验同类、启用且修订一致，再将 ID、修订号、名称、正文保存到项目；不信任客户端正文。已建项目只合并变更的分类，未提交分类绝不重新解析。旧客户端新建时的 `builtin`/省略项解析本类当前默认；旧客户端对已有项目显式提交 `builtin` 视为主动改回当前默认，省略的更新不变。
- 不能只给旧 `builtin` 加一个 ID：现有文本生成明确忽略 `builtin` 的正文快照，故事板也会直接返回代码正文。新 `preset` 必须在正文选择、规划容量预估、任务主快照及顺带调用（例如资产拆解同时生成资产图提示词）中走项目/任务快照。故事板从项目返回的已存 `board` 正文拼宫格，提交后沿用该次任务的输入。正文缺损应明确失败，不可悄悄用另一条模板。研读、固定格式化阶段、输入变量和输出协议继续由代码控制。
- 个人历史项目快照不改变；新建个人模板以目录默认正文起草，后续不随默认更新。旧项目里没有新 `preset` 的 `builtin` 和旧任务走原内置兼容路径，不需要批量回写项目，也不解析当前后台默认。保留原分集规划失败恢复入口：用户明确点击「改用原内置重试」时只把分集规划切到升级前原版，再恢复运行；不能用可能同样出错的当前后台默认冒充救援方案。
- 迁移从升级前的六份实际正文各导入一条「标准版」并启用为各自默认，使用稳定种子键做幂等插入，重启、重跑迁移或升级不覆盖后台修改。兼容原版不依赖可编辑的种子记录。对外开放前部署所有能识别 `preset` 快照的 API 和任务执行器；回滚先关闭新选用和后台写入，但保留读快照的兼容代码，不直接回退到不认识该类型的执行器。

## 5. 实施与验收

顺序建议：① 增加种子迁移、后台权限、目录和并发保护；② 接通六类快照、估算、故事板与失败恢复，覆盖老任务；③ 接入后台页面和两个用户选择器；④ 在预发先保持六类标准版不变，验证一致后再新增真实运营模板。

| AC | Given / When / Then | 验证位置 |
| --- | --- | --- |
| AC01 初始默认 | Given 新旧数据库；When 执行初始化或重试；Then 六类各一条已启用默认，正文与升级前一致，管理员改动不被覆盖 | 后端迁移集成 |
| AC02 默认不变量 | Given 某类 A 默认、B 启用；When 并发切换到 B 与停用 B，或直接下架唯一默认；Then 不可能提交无有效默认的状态，冲突方收到明确提示 | 后端 PostgreSQL 并发测试 |
| AC03 选择与保留 | Given 一类多条内置和个人模板；When 在开拍或项目设置选择并保存；Then 只变更所选类别，原有技能、个人模板和剧本型限制不变 | 前端组件/页面、后端接口 |
| AC04 旧剧不漂移 | Given 项目与任务已锁定 A；When 管理员改正文、切默认或下架 A；Then 原项目与原任务仍用保存的正文，新项目预选新默认，旧项目下架状态有提示 | 后端快照、前端显示 |
| AC05 过期与越权 | Given 过期模板/项目修订、跨类 ID、停用项或普通账号调用管理接口；When 提交；Then 返回对应冲突或拒绝，不替换、不部分保存，普通目录不泄露管理数据 | 后端接口、前端错误态 |
| AC06 特殊链路 | Given 可识别的不同正文；When 估算/执行规划、拆解时顺带写资产图提示词、提交故事板或触发规划兜底；Then 分别使用该环节锁定的正文，非法故事板占位符被拒，兜底只改变规划 | 后端任务/故事板、前端拼接 |
| AC07 历史兼容 | Given 升级前的内置、个人和技能项目及排队任务；When 升级后运行并切换新版默认；Then 不改写历史设置、不将旧内置静默切到新版默认 | 后端服务及升级验收 |

验证入口：`go test ./internal/tests/{migration,service,handler} -run TestDramaPreset`（在 `backend/` 下，迁移测试需要 `TEST_DATABASE_DSN`）；前端在 `web/` 下跑 `bun test src/tests/components/drama/prompts.test.tsx src/tests/pages/drama/project-settings.test.tsx`；完整验证走仓库根目录 `bash scripts/check.sh backend web`。
