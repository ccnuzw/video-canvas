成片粗剪

在「成片」页里直接粗剪一集

现在「合成整集」只能把每个片段采用的视频整段、按顺序拼起来。这次把成片页变成一个剪辑台：时间线按片段顺序自动铺好，可以裁头尾、拆分、删除、换顺序、换版本、插入画布素材或本地视频/图片、静音，然后照旧点「合成第 N 集」。 只做一条视频轨的粗剪，不做音乐轨、转场、字幕。不剪直接合成，结果和今天完全一样。

阅读说明。现状来自仓库 origin/master 的代码（成片页 final-area.tsx、合成任务 drama_compose.go）；剪辑台、接口、数据表都是提案，尚未实现。原型里的视频是色块示意，不调用任何服务。完整依据见 成片粗剪.md。

一集从片场到成片怎么走

剪辑台只多了一份「剪辑清单」，渲染仍交给已有的后端合成任务。

片场采用每个片段选一条 take 现有
时间线自动铺好按片段顺序、全长，跟随采用 提案
粗剪裁、拆、删、移、换、插、静音；停手 1 秒自动保存清单 提案
合成第 N 集提交时把清单冻结成「素材 + 入出点」 提案
后端 ffmpeg逐段裁剪、统一到项目比例、拼接，不扣积分 现有，需改造
设计：时间线只存决定（非破坏），原片段和素材不动；渲染放后端是因为成片要落进素材库、能被下载和分享，并且现有合成任务已经处理了进度推送、取消、重试和失败回收。浏览器渲染被放弃：编码时不能关页、长片吃内存、Safari 支持差。
兜底：这一集从没剪过 → 后端现算一份默认时间线（全部片段顺序全长），合成结果与今天一致。片段还没采用 → 轨上是「待采用」斜纹占位，合成时跳过并提示。固定的版本或素材被删 → 段标红，合成按钮禁用直到换掉或删掉。缩略图取不到 → 段显示纯色，不影响剪辑和合成。

时间线上会出现四种段

段的来源决定它会不会被片场的改动带着走。

片段 · 跟随
默认

绑定分镜片段的当前采用。片场换了采用版本，这段自动换素材，入出点尽量保留。

片段 · 固定版本
不跟随片场

在时间线里手动换过版本。片场再换采用也不动它；右键「跟随采用」可恢复。

素材
画布 / 本地导入

视频或图片。视频可裁入出点；图片拖边改时长，默认 3 秒，0.5–30 秒。

待采用占位
合成时跳过

片段还没有采用视频。按片段秒数占位，片场采用后自动变成跟随段。

剪过之后又去片场改了，会发生什么

时间线跟着片场走，但不覆盖你在时间线里亲手做的选择。可以去「片场同步规则」页逐条试。

  1. 在成片页把片段 02 掐掉了开头 2 秒清单里记 in=2s；自动保存
  2. 回片场把片段 02 改采用「版本 3」，又新增了片段 05片场推送 drama.segment
  3. 回到成片页：标题旁出现「片场更新 2」小胶囊，改动的段带蓝色描边片段 02 换成版本 3，仍掐掉开头 2 秒；片段 05 插在片段 04 后面（还没采用就是占位）
  4. 点开胶囊可逐条定位；不满意点「撤销同步」或 ⌘Z同步被当成一步操作放进撤销栈
边界：入出点是按旧素材定的
  • 新版本更短：出点收回到新长度；入点也越界就恢复全长。
  • 新版本内容完全不同，原来的掐头位置可能不再合适，需要用户自己再看一遍。
  • 在时间线里删掉的片段，片场再改也不会被自动加回来；可以从左侧「片段」重新拖入。
  • 合成正在跑时继续剪不会影响这次合成（输入已冻结），但新成片一出来就显示「已过期」。

上线时要告诉用户：「合成第 N 集」现在按时间线合成；没动过时间线的集行为不变。

关系

时间线是「一集」的派生数据，不放进画布 payload。

对象关系为什么
集 ↔ 时间线1 : 0..1，episode_id 唯一没保存过就现算默认时间线，第一次保存才落库
时间线段 → 片段segment_id，可多段指向同一片段拆分后两段同源；片段被删时对账移除
时间线段 → taketask_id + pinned跟随时由对账写入当前采用；固定时由用户选
时间线段 → 素材asset_id（画布素材或本地导入）合成按 asset 下载，必须校验归属当前用户
时间线 ↔ 画布无直接关系画布有自己的 revision，剪辑高频保存不能和画布编辑互相冲突

// reconcile（提案）—— GET 时间线与合成任务共用同一份 Go 实现
func reconcile(tl, segments) (tl2, changes):
  for clip in tl.clips where clip.kind == "segment":
    seg := segments[clip.segment_id]
    if seg == nil:                         移除 clip；changes += "片段 NN 已删除"
    else if !clip.pinned:
      if seg.chosen == "":                 clip.task_id = ""（变占位）；changes += "片段 NN 取消了采用"
      else if seg.chosen != clip.task_id:  clip.task_id = seg.chosen；clampTrim(clip, dur(seg.chosen))
                                           changes += "片段 NN 换了采用版本"
    else if take 不再成功或素材缺失:        标记 invalid
  for seg in segments 按 seq:
    if 轨上没有 seg 且 seg.id ∉ removed_segment_ids:
      插到「最后一个 seq 比它小的片段段」之后（没有就放最前），全长、跟随
      changes += "新增片段 NN"
  removed_segment_ids 去掉已不存在的片段

clampTrim(clip, dur): clip.out = min(clip.out, dur)；if clip.in > clip.out - 500 { clip.in, clip.out = 0, dur }

已确认的决定

  1. 后端 ffmpeg 渲染，时间线只存剪辑清单：复用现有合成任务，关页不丢。
  2. 四类操作都做：裁头尾 + 拆分 + 删除、拖动排序、换用同片段其他版本、插入外部素材（画布 / 本地导入的视频和图片）。
  3. 声音只做单轨 + 静音：整轨和单段静音；音乐轨已搁置，将来加一条音频轨、合成改 amix。
  4. 成片页直接变剪辑台：不做全屏弹窗。
  5. 自动跟随片场 + 提示：时间线里手动换过版本的段不跟随；「冻结 + 手动同步」已搁置。
