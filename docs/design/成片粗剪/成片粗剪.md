# 短剧「成片」页粗剪设计

> **范围**：短剧工作区「成片」页的粗剪剪辑台——把一集已采用的片段视频放上一条时间线，裁头尾、拆分、删除、拖动排序、换用同片段的其他版本、插入画布素材或本地导入的视频/图片、整轨或单段静音，最后用后端 ffmpeg 按剪辑清单合成整集。
> **日期与状态**：2026-11-26，设计中（访谈完成，待实现）。分支 `feat/drama-rough-cut`（从 `origin/master` 拉出）。
> **证据约定**：**事实**附文件路径；**推断**是基于事实的判断；**提案**是尚未实现的设计；**未验证**需要实现时实测。
> **方案演进**：（2026-11-26 补）用户看原型后认为横跨整页的同步提示条难看且会挤压剪辑台，改为顶栏胶囊 + 浮层 + 轨上段标记（§7）。起点是用户给的两张图（图 1 现在的成片页；图 2 参考时间线：左素材「已导入资产 / 画布资产」、右预览、下单轨时间线，工具条有撤销/重做/拆分/向左裁/向右裁/删除和缩放）。访谈中没有转向，6 个决定见 §11。
> **配套演示**：[成片粗剪-演示.html](成片粗剪-演示.html)（含可点击原型：剪辑、换版本、片场变更同步、合成成功与失败都能走一遍；全部是模拟数据）。

## 1. 设计摘要

- **问题**：现在「合成整集」只能把每个片段采用的视频**整段、按片段顺序**拼起来。AI 视频常带多余的开头/结尾，或者想把某段换个位置、插一个空镜，只能下载后去剪映里做，成片和项目脱节。
- **目标**：在成片页里完成一集的粗剪，合成出的成片仍是这一集的 `final`，下载、分享、过期提示都照旧。
- **推荐结论**：
  1. **成片页直接变剪辑台**：左分集栏不动；主体变成「左素材 + 右预览 + 下时间线」；原来右侧的合成面板收进顶部一行（统计 + 「合成第 N 集」）。（用户确认）
  2. **时间线只存剪辑清单，后端 ffmpeg 渲染**：每段记「素材 + 入点 + 出点 + 是否静音」；「合成整集」任务读清单裁剪再拼接，复用现有 `compose` 任务、进度推送和成片过期逻辑，不扣积分。（用户确认）
  3. **单条视频轨，始终首尾相接（磁吸）**，没有空隙、没有多轨；声音只有整轨静音和单段静音。（用户确认）
  4. **片段绑定分镜，自动跟随片场**：片场换了采用版本、增删片段，时间线自动同步，提示不占布局：标题旁一个「片场更新 N」小胶囊 + 轨上改动段的蓝色标记；在时间线里手动换过版本的段不再跟随。（用户确认）
  5. **自研时间线和预览**，不引新依赖；缩略图复用已有的 Mediabunny 取帧。（用户确认）
- **第一版刻意不做**：多轨、BGM/配音轨、转场、字幕、调速、调色、关键帧、画面裁切缩放、多人同时编辑、导出 XML/EDL 给剪映（见 §10）。

### 2.2 设计约束（推断）

- 合成必须仍在后端跑：成片要落在用户素材里、被下载/分享/交付，且现有任务系统已经处理了取消、重试和对象回收。
- 合成输入必须继续「提交时冻结」：把清单里的每段解析成具体 `asset_id + in/out` 后写进 `input_json`，之后剪辑台再改也不影响正在跑的任务。
- 时间线是**这一集的派生数据**，不能放进画布 `payload_json`（画布有自己的 revision，剪辑时频繁保存会和画布编辑互相冲突）。
- 片场会持续改动片段，时间线必须能和片段列表对账，对账规则要在 Go 里实现一份（合成用），前端只展示结果。

### 2.3 当前缺口

- 没有任何时间线/剪辑数据结构和接口。
- `Compose` 只能整段拼接，不支持入出点、图片、单段静音；目标分辨率取第一段，不保证项目比例。
- 没有「列出这部剧画布上可用的视频/图片」的轻量接口（画布 payload 很大，不宜为素材面板整份拉取）。

## 3. 用户与场景

- **用户**：在短剧工作区出片的创作者，熟悉剪映这类工具，但不想为了掐头去尾离开项目。
- **触发场景**：① 片段 AI 视频开头 1 秒定格、结尾穿帮；② 两个片段之间想插一张空镜图或一段画布上做过的视频；③ 某段采用的版本节奏不对，想在剪辑时直接换另一条 take 看效果；④ 某段音效很吵，想静音。
- **主任务**：进入成片 → 时间线已按片段顺序铺好 → 拖边裁掉头尾 / 拆分删一截 → 预览 → 合成 → 下载。
- **成功指标（提案）**：一集 4 段的常规粗剪 2 分钟内完成；合成后的成片时长与时间线显示时长误差 ≤ 1 帧（33ms）；剪辑台打开到可播放 ≤ 2 秒（示意，需实测）。

## 4. 调研范围

> 调研受限说明：本次未逐页抓取官网，以下产品观察来自已有知识，状态均为「调研检索，未逐条复核」；交互细节以本项目访谈结论为准。访问日期 2026-11-26。

### 4.1 产品交互

| 方案 | 观察 | 对本项目的启发 | 不适合的地方 |
| --- | --- | --- | --- |
| **用户参考图（时间线弹窗）** | 左「已导入资产 / 画布资产」+ 全部/图片/视频/音频筛选 + 「导入」；右预览带播放/时码/适配/音量/全屏；下单轨，工具条撤销、重做、拆分、向左裁、向右裁、删除，右侧吸附开关与缩放 | 整体布局与工具条照做 | 它是弹窗；用户选择嵌进成片页（§11 决定 4） |
| **剪映 / CapCut** | 主轨默认磁吸、片段首尾相接；选中片段拖两边裁剪；播放头处「分割」；左侧素材拖进主轨插入 | 主轨磁吸 = 粗剪最省心的心智，第一版只做这条主轨 | 多轨、贴纸、特效与粗剪无关 |
| **Premiere Pro / DaVinci Resolve** | 波纹删除（Ripple Delete）、Q/W 裁到播放头（Ripple Trim Previous/Next）、J/K/L 播放 | 「向左裁 / 向右裁」= 裁到播放头并波纹，参考图的两个按钮就是它 | 专业 NLE 的轨道、Bin、序列设置太重 |
| **Descript / Clipchamp** | 非破坏剪辑：原素材不动，只存剪辑决定；导出时渲染 | 时间线存「剪辑清单」而不是剪出新文件，与后端渲染吻合 | Descript 以文稿驱动，不适合视频片段 |

**结论**：几家在「主轨磁吸 + 拖边裁剪 + 播放头分割 + 非破坏」上没有分歧，直接采用；差异只在多轨和特效，第一版不做。

## 5. 设计原则

1. **剪辑是非破坏的**：原片段、take、素材都不动，时间线只存决定；随时可「恢复原长」。（来源：Descript/Clipchamp 观察 + 现有合成冻结输入的做法）
2. **默认就是能合成的状态**：进入成片页时间线已按片段顺序铺好，不剪直接合成 = 今天的行为。（来源：现有 `composeInput`）
3. **跟随片场、手动优先**：没手动动过版本的段跟着片场走；用户在时间线里做的选择不被片场覆盖。（来源：§11 决定 5）
4. **一条轨、无空隙**：粗剪只关心「留哪些、什么顺序」，不提供需要对齐的自由摆放。（来源：§11 决定 2/3、剪映主轨）
5. **预览即成片**：预览按清单播放，时长、顺序、静音与合成结果一致；做不到帧级一致的地方明说。

## 6. 推荐方案

### 6.1 信息架构

```
成片页（stage = final）
├─ 左：分集栏（不变）
└─ 主体
   ├─ 顶栏：第 N 集 · 标题 | 保存失败时的「重试」| 片场更新胶囊（有对账变更时出现）| 导出（唯一的按钮：保存时间线 → 后端 ffmpeg 合成 → 自动下载 mp4；进行中按钮上显示「保存中… / 合成中 x% / 下载中…」；不能导出的原因只放在悬停提示里）
   ├─ 中部
   │  ├─ 素材面板（默认 300px，可拖动调宽）：标签「片段 / 画布素材 / 已导入」+ 筛选「全部 / 视频 / 图片」+ 「导入」；卡片上面缩略图（图片 `?v=thumb`、视频 `?v=poster`，和画布同一套）、下面名字和时长，按宽度自动排列（每张至少 120px）；「片段」只列有可用视频的片段，一个都没有就留空
   │  └─ 预览：只按时间线播放（不再分「时间线 / 成片」），播放/时码/静音
   └─ 时间线：工具条（撤销 重做 | 拆分 向左裁 向右裁 | 删除 ……右侧 吸附提示 缩放 −/滑杆/+）
              刻度尺 + 播放头
              视频轨（左侧整轨静音按钮）
```

- 原右侧合成面板的「缺视频提示」→ 变成轨上的「待采用」占位段；「片段清单」→ 变成素材面板「片段」标签。
- 竖屏项目（比例高大于宽，如 9:16）：预览放在右侧整列（从顶栏下到底部），左侧上面是素材面板、下面是时间线。横屏项目（如 16:9）保持上面素材 + 预览、下面时间线。（2026-11-26 用户看实际页面后确认）
- 所有分栏的边都能拖动调节（react-resizable-panels，和片场同一个库），每人拖出的尺寸存在浏览器里，竖屏和横屏各存一份；默认：时间线 232px 高，竖屏预览列 400px 宽，横屏素材面板 300px 宽。
- 顶栏不放「已采用 x/y」「时间线时长」统计。（2026-11-26 用户确认去掉）

### 6.2 时间线上的段（Clip）

| 类型 | 来源 | 外观 | 可做的操作 |
| --- | --- | --- | --- |
| 片段段（跟随） | 分镜片段的**当前采用** take | 缩略图条 + 左上「片段 02」 | 裁剪、拆分、删除、移动、静音、换版本（换后变固定） |
| 片段段（固定版本） | 用户在时间线里选的某条 take | 同上 + 「📌 版本 3」角标 | 同上 + 「恢复跟随采用」 |
| 待采用占位 | 片段还没有采用视频 | 斜纹灰块，宽度 = 片段 `seconds`，文字「片段 04 · 待采用」 | 删除、移动、去片场；**合成时跳过** |
| 素材段 · 视频 | 画布素材或本地导入的视频 | 缩略图条 + 文件名 | 裁剪、拆分、删除、移动、静音 |
| 素材段 · 图片 | 画布素材或本地导入的图片 | 单张图平铺 | 拖边改时长（0.5–30s，默认 3s）、拆分、删除、移动 |
| 失效段 | 固定的 take / 素材被删 | 红色描边「素材已失效」 | 删除、换版本；合成前必须处理（否则合成按钮禁用） |

### 6.3 核心交互

- **选中**：单击段选中（黄色描边）；点轨道空白处取消。第一版只支持单选。
- **裁剪**：拖选中段的左/右边缘；不能超出素材本身长度（视频）；最短 0.5s；磁吸，后面的段跟着移动。拖动时边缘浮出新时长胶囊。
- **拆分**：播放头落在某段内部时「拆分」可用（快捷键 `S`），一段变两段，各自保留同一来源。
- **向左裁 / 向右裁**：把选中段（没选中则播放头所在段）播放头左侧/右侧的部分删掉，波纹前移（`Q` / `W`）。
- **删除**：删除选中段（`Delete/Backspace`），后面的前移。删掉的是片段段时，记入 `removed_segment_ids`，对账不会再自动加回；从「片段」标签可再拖回来。
- **移动**：长按拖动段，插入位置显示黄色竖线，松手插入；磁吸无空隙。
- **插入素材**：从素材面板拖到轨道某个插入点；或点素材卡上的「+」追加到播放头所在段之后。
- **换版本**：右键段（或选中后在段上的「⋯」）→「换版本」子菜单列出该片段所有成功 take（带缩略图、时长、「采用」标记）；选非采用版本 → 变固定；选「跟随采用」→ 恢复跟随。换版本时入出点保留，超出新素材长度就收回到新长度；入点也越界则恢复全长。
- **静音**：轨道左侧喇叭 = 整轨静音；段右键「静音此段」= 单段静音（段上显示静音图标）。
- **撤销/重做**：会话内存栈，最多 100 步（`⌘Z` / `⇧⌘Z`）；切集或刷新清空。
- **缩放**：`−` / 滑杆 / `+`，以及 `⌘ + 滚轮`；默认「整集适配宽度」。
- **播放**：空格播放/暂停；点刻度尺定位；拖播放头时预览显示该帧。
- **素材面板「片段」标签**：按片段顺序列出每个片段的所有成功 take，标「已采用」「已在时间线」；可拖进时间线（拖入的是固定版本段，除非拖的是采用版本则为跟随段）。

### 6.4 预览

- 两个 `<video>` 交替：当前段播放时，另一个预加载下一段并 seek 到其入点；当前段到出点时切换显示，实现近乎无缝的连播（**未验证**：切换可能有 1 帧左右的闪动，需实测）。
- 图片段用 `<img>` 按时长计时显示；待采用占位显示黑底 + 「片段 04 待采用，合成时跳过」。
- 静音段播放时静音；整轨静音时预览全程静音。
- 预览只有一种：按时间线播放。已合成的成片不在页面上播放，「导出」直接下载。（2026-11-26 用户确认）
- 预览按项目比例显示，非项目比例的素材**加黑边居中**（与合成一致）。

### 6.5 合成（界面上叫「导出」）

- 2026-11-26 用户确认：顶栏只放一个「导出」按钮，不显示成片状态、下载和合成。点「导出」：先保存时间线；时间线合成后没改过（成片不过期）就直接下载上次的成片；否则提交合成任务，任务成功、详情刷出新成片后自动下载；任务失败或取消就停下，原因看任务卡。共享只读只能下载作者已有的成片。
- 以下是原设计，接口层面不变：


- 「合成第 N 集」：先把未保存的清单立即保存（等保存成功），再提交 `compose` 任务。
- 后端把清单冻结成合成输入；跳过待采用占位段；有失效段则拒绝（67033）。
- 合成成功提示沿用 `composeNotice`；跳过的提示改成「跳过了待采用的片段 04」。
- 成片过期：保存时间线会让 `SegmentVersion` 自增，所以「合成后又剪了」也会显示「成片已过期，可重新合成」。

## 7. 状态与异常

| 状态 | 表现 |
| --- | --- |
| 加载中 | 素材面板、预览、轨道显示骨架；轨道先按片段 `seconds` 画占位，缩略图异步补齐 |
| 没有片段 | 沿用现在的空状态「第 N 集还没有成片」+「去片场」；素材面板「画布素材 / 已导入」仍可用 |
| 全部待采用 | 轨上全是占位段；合成按钮禁用，原因「至少要有一个片段采用了视频才能合成」 |
| 编辑中 | 顶栏「未保存」灰点 → 停止操作 1s 后自动保存 |
| 保存中 / 已保存 | 「保存中…」/「已保存」 |
| 保存失败 | 「保存失败 · 重试」；本地状态保留；合成按钮禁用（原因：先保存时间线） |
| 冲突（409/67031） | 别的标签页改过：toast「时间线在别处被修改，已载入最新版本」，载入服务端版本，撤销栈清空 |
| 片场有更新 | 打开或收到 `drama.segment` 推送后重新对账。**不插横幅、不挤压布局**：① 标题旁出现蓝色胶囊「🔄 片场更新 N」，点开浮层逐条列出改动（「片段 02 换成了采用的版本 3」「新增片段 05（待采用）」「片段 03 已删除」），有对应段的条目可点击定位（选中该段、播放头跳到段首、时间线滚到可见）；浮层底部「撤销同步」（把本次对账前的清单放回撤销栈顶）和「知道了」；② 轨上被同步改过或新增的段加蓝色描边 + 右上角蓝点。点「知道了」或撤销后胶囊和标记一起消失；多次推送的改动累加到同一个胶囊里。 |
| 合成中 | 主按钮变进度条；时间线**仍可编辑**（合成用的是冻结输入；改动会让新成片立即过期） |
| 合成失败 | 沿用任务卡失败文案（下载失败 / 转码失败 + 重试）；时间线不受影响 |
| 失效段 | 红框 + 合成按钮禁用「片段 03 版本 2 已被删除，请换版本或删掉」 |
| 共享只读 | 时间线和预览可看可播，所有编辑、导入、合成隐藏 |
| 导入失败 | 素材卡显示「上传失败 · 重试」；超 200MB 在选择文件时就拦下 |
| 浏览器取不到缩略图 | 段内显示纯色 + 文件名，不影响剪辑和合成 |

`TimelineClip`：

```jsonc
{
  "id": "c_8f2a",             // 前端生成，清单内唯一，≤ 32 字符
  "kind": "segment" | "asset",
  "segment_id": "123",        // kind=segment
  "task_id": "456",           // kind=segment：当前解析到的 take；跟随时 = 采用的 take，空 = 待采用
  "pinned": false,            // kind=segment：true = 固定版本，不跟随采用

  "out_ms": 15000,            // 视频：出点（≤ 素材时长）；图片：时长（500–30000）
  "muted": false
}
```

约束：`out_ms - in_ms ≥ 500`；clips ≤ 200；总时长 ≤ 30 分钟；同一 `segment_id` 可出现多次（拆分后）。

### 8.2 对账（Go 实现一份，GET 与合成共用）

```
reconcile(tl, segments, tasks) -> (tl', changes[])
  for clip in tl.clips where kind=segment:
    seg := segments[clip.segment_id]
    if seg 不存在: 移除 clip；changes += removed(seq)
    elif !clip.pinned:
      if seg.chosen == "": clip.task_id = ""（变待采用）；changes += unadopted
      elif seg.chosen != clip.task_id:
        clip.task_id = seg.chosen；clampTrim(clip, duration(seg.chosen))；changes += swapped
    elif clip.task 不再成功/素材缺失: 标记 invalid
  for seg in segments 按 seq:
    if seg 不在任何 clip 且 seg.id ∉ removed_segment_ids:
      插到「最后一个 seq < seg.seq 的片段段」之后，找不到则放最前；全长；跟随
      changes += added(seq)
  removed_segment_ids 去掉已不存在的片段
clampTrim: out = min(out, dur)；若 in ≥ out-500 则 in=0,out=dur
```

- GET 返回对账后的清单 + `changes`，**不写库**；前端下一次保存时自然落库。
- `kind=asset` 素材被删 → 标记 invalid（不移除，让用户看到）。

### 8.4 合成改造

```go
type composeClip struct {
    AssetID uint64 `json:"asset_id"`
    Media   string `json:"media"`   // video | image
    InMS    int64  `json:"in_ms"`
    OutMS   int64  `json:"out_ms"`
```

- 超时：总时长变长后 10 分钟可能不够，改为 `max(10min, 总时长 × 2)`，上限 30 分钟（**提案**，需实测转码速度）。

### 14.3 原型里的规则（提案，待实现时细化）

- **显示与叠放**：从上到下 字幕 → 叠加（上面的盖住下面的）→ 主轨 → 音频；新加的叠加轨放在最上层。每类上限：叠加/字幕 4 条，音频 6 条。
- **轨道头**：编号 + 名称；字幕轨「+」（播放头处加 2 秒字幕）、隐藏、锁定、「⋯」（按台词生成、删除轨道）；叠加轨隐藏、静音、锁定、「⋯」；音频轨静音、锁定、「⋯」；主轨只有整轨静音。
- **附属片段**：`start + len + in`（源入点）+ 音量 0–200% + 淡入/淡出（各 ≤ 3s）；叠加另有 `x/y`（中心点百分比）、`scale`（占画面宽度 %）、`opacity`，预设「铺满 / 右上小窗 / 左下小窗 / 居中」；字幕有 `text`、样式（字幕/标题）、位置（顶/中/底）、字号。
- **交互**：自由拖动，只能跨同类轨；同轨不重叠，松手落在占用位置就回退并提示；拖边裁剪不能超出素材长度和相邻片段；吸附（0、播放头、主轨剪辑点、其他片段首尾，8px，工具条磁铁开关 / `N`）并画吸附线；淡入淡出手柄在片段上沿直接拖；拆分 / 向左裁 / 向右裁 / 删除对选中的附属片段同样有效但不波纹。
- **拖入规则**：片段版本、视频、图片 → 主轨（插入）或叠加轨（落点放置）；音频 → 音频轨；素材卡「+」：画面插到主轨播放头所在段之后，音频放到播放头处同角色且空着的音频轨，没有就新开一条。
- **按台词生成字幕**：每个片段的台词按采用视频的时长均分，再按入出点裁到时间线上，替换该字幕轨原有内容（可撤销）。片段台词来源待核对（剧本结构化台词）。
- **预览**：主轨画面 + 叠加画面（按位置/缩放/不透明度/淡变）+ 字幕；音频在画面角上列出正在响的素材名（原型示意，实际要混音）。
- **导出**：附属轨里有失效素材时禁用导出；后端合成需从「按清单裁剪拼接」扩展为 filtergraph（`overlay` 叠画面、`amix` 混音、`afade`/`fade` 淡变、`subtitles`/`drawtext` 烧字幕）。

### 14.6 接口契约（多轨，`GET/PUT /dramas/:id/episodes/:no/timeline`）

响应（GET 与 PUT 成功后相同）：

```jsonc
{
  "tracks": [Track, ...],          // 显示顺序：字幕 → 叠加 → 主轨 → 音频；各类内部也按这个顺序
  "removed_segment_ids": ["..."],  // 同前
  "imports": ["..."],              // 同前，可含音频素材
  "revision": 3,                   // 同前，0 = 还没保存过（默认时间线）
  "changes": [...],                // 同前，只来自主轨对账
  "invalid_clip_ids": ["..."],     // 所有轨上失效的片段
  "assets": [AssetView, ...]       // 所有轨与 imports 引用到的素材（可含 audio）
}
```

`PUT` 请求体 = `{revision, tracks, removed_segment_ids, imports}`（不再有顶层 `clips` 和 `muted`）。

```jsonc
Track {
  "id": "tk_ab12",                 // ≤32，时间线内唯一；主轨固定叫 "main"
  "kind": "main" | "overlay" | "audio" | "text",
  "role": "voice" | "music" | "sfx",   // 只有 audio 轨有，缺省 sfx
  "name": "配音",                  // ≤20 字
  "muted": false, "hidden": false, "locked": false,
  "clips": [Clip, ...]
}
Clip {
  "id": "c_..",                    // ≤32，整条时间线内唯一
  "kind": "segment" | "asset" | "text",
  // kind=segment：segment_id / task_id / pinned（主轨 task_id=0 为待采用占位；附属轨必须有 task_id 且 pinned 视为 true）
  // kind=asset：asset_id / media（video|image|audio）
  // kind=text：text / style(subtitle|title) / pos(top|middle|bottom) / size(60–180)
  "in_ms": 0, "out_ms": 4000,      // 时长 = out_ms - in_ms，所有轨一致；图片和文字 in_ms 恒为 0
  "start_ms": 2000,                // 附属轨必填（≥0）；主轨不存，按顺序首尾相接
  "muted": false,
  "volume": 100,                   // 0–200，始终序列化（0 = 静音），server 默认时间线写 100
  "fade_in_ms": 0, "fade_out_ms": 0,   // 各 ≥0，两者之和 ≤ 时长；text 不用
  "x": 50, "y": 50, "scale": 100, "opacity": 100   // 只有叠加轨用：0–100 / 0–100 / 10–100 / 0–100
}
```

校验（`67047`，Msg 写「轨道名 第 N 段：原因」）：主轨恰好 1 条；叠加 ≤ 4、字幕 ≤ 4、音频 ≤ 6；每轨 ≤ 200 段、全部 ≤ 400 段；叠加轨只收 video/image（或片段版本），音频轨只收 audio 素材，字幕轨只收 text，主轨只收 segment/asset(video|image)；附属轨同轨不得重叠；每段时长 ≥ 500ms；整条时间线结束点 ≤ 30 分钟；其余沿用现有校验（版本归属、素材归属与种类、不超出素材长度）。
默认时间线（没保存过）：`[字幕(空), 叠加(空), 主轨(按片段全长铺好), 配音(空, role=voice), BGM(空, role=music)]`，轨 id 固定为 `text1 / overlay1 / main / voice1 / music1`。

### 14.8 多轨合成（2026-11-27）

- **冻结**：提交合成时所有轨都冻结进任务输入（`tracks`：叠加 / 音频 / 字幕平铺列表）。隐藏的叠加轨和字幕轨、静音的音频轨、静音或音量为 0 的音频片段冻结时就剔除；叠加轨上的片段版本换成该版本的视频素材。没有任何附属轨内容时输入里不带 `tracks`，走原来的主轨拼接路径，结果与之前一致；旧任务（只有 `asset_ids` 或只有 `clips`）照旧。
- **渲染**（`videoframe.ComposeTimeline`）：先按原逻辑把主轨转码拼成统一规格的底片（主轨片段现在也带音量和淡入淡出，画面淡到黑），再用一张滤镜图（写进文件，ffmpeg 7 用 `-/filter_complex`，旧版退回 `-filter_complex_script`）完成：
  - 成片总长 = 全部轨的最晚结束点，主轨短时 `tpad` 补黑、`apad` 补静音；
  - 叠加画面按「下面的轨先、上面的轨后」逐个 `overlay`：宽度占比缩放、中心点定位、淡入淡出作用于透明度、整体不透明度、`enable` 限定时间段；
  - 声音：底片声音 + 叠加视频自带的声音 + 音频轨，各自 `volume`（0–200%）/ `afade` / `adelay` 后 `amix`（`normalize=0`），最后 `alimiter` 防爆音；
  - 字幕生成 ASS 文件用 `ass` 滤镜烧录，后端按字宽自行换行，字号、位置（顶 12% / 中 / 底 9%）与预览对齐，用户文字里的 `{ } \` 转成全角避免被当成样式标签。
- **字体**：`ass`（libass）随 ffmpeg 已装好，按字体名「Noto Sans CJK SC」找字体；镜像加装 `font-noto-cjk`（`backend/Dockerfile`），否则中文会是方块。选 ASS 而不是 `drawtext`：libass 有字体回退和描边，多行和定位更省事，不用在命令里转义文字。
- **超时**：有附属轨时按成片时长 3 倍放宽（仍在 10–30 分钟之间）。
- **与预览的已知差异**：字幕字宽按估算换行，个别字体下换行位置可能和浏览器略有不同；音量超过 100% 时成片会经过限幅，预览不限幅；预览里跨域素材音量放大不生效（只到 100%），成片按设定音量。

- 键盘：→ 下一步，← 上一步，Esc 跳过（driver.js 自带 `allowKeyboardControl`）。点遮罩不关闭（`overlayClickBehavior` 设为空操作），防止误触跳过。
- 与 coding-standards 6.2「不加操作说明小字」的关系：引导是用户主动要的一次性浮层，不常驻页面，不算说明小字；页面本身仍不加任何说明文字。
- 重看入口：顶栏全屏按钮左边，`CircleHelp` 图标，圆形 32px ghost 按钮，`title="新手引导"`。

### 15.6 动效

| 触发 | 属性 | 时长 / 曲线 | 方向 |
| - | - | - | - |
| 引导开始 | 遮罩 opacity 0→1，气泡 opacity 0→1 + translateY 4px→0 | `DURATION.base` 180ms，`EASE_OUT` | 气泡从目标方向出来 |
| 切换步骤 | 高亮洞由 driver.js 补间到新目标 | driver.js 内置约 400ms | 跟随目标 |
| 跳过 / 完成 | 遮罩和气泡 opacity →0 | `DURATION.exit` 126ms | 原地淡出 |

driver.js 切步的高亮补间时长不可配，超出 250ms 上限；接受这一点，因为它是空间连续性动画，不阻塞输入（随时可按下一步）。`prefers-reduced-motion` 时传 `animate: false`，气泡只淡入。

### 15.7 状态

| 状态 | 表现 |
| - | - |
| 时间线加载中 | 不开始；`status === "ready"` 后延迟 400ms（等页面入场动画播完）再自动开始 |
| 打开了导出单、片场更新弹层等浮层 | 不自动开始；用户点「?」手动开始时先关不了的浮层不处理 |
| 共享画布（`shared`）只读访客 | 走只读的 3 步 |
| 剪辑台全屏 | 正常播；导出按钮在全屏下仍在顶栏 |
| 窄屏 < 768px | 剪辑台本身有最小宽度；气泡宽度 `min(280px, 100vw - 32px)`，driver.js 放不下时自动翻转 |
| 切集 | 引导中切集直接结束引导，照样记为已看 |
