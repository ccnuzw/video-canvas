设计标注

  1. 元素工具条：当前行的类型高亮；不合法的类型置灰并在悬停里写原因，不隐藏。Tab / Shift+Tab 循环切换，Enter 按规则接下一种（角色、括号 → 对白，对白 → 动作）。取代了手打「人物（语气）：台词」。
  2. 角色行是选择器，不是文字：存人物 ID，显示正式名；输入时按名字和别名匹配，没有就「新建人物」。对白永远挂在角色下面，所以格式乱不了。
  3. 场次标题由三个控件拼成：内外、时间、地点（来自地点表），和拆解、分镜用同一个地点身份；场号由顺序推出，不单独存。
  4. 保存：停手 1.5 秒整集保存（PUT …/script），集级 revision 乐观锁；冲突和锁定沿用现有 DocEditor 的处理。
  5. 场次栏：短标题、梗概、情绪本期手填，B（跨集状态提取）上线后自动填；拖动调整场次顺序。
  6. 人物表：蓝点 =「待确认」，是解析剧本时自动登记的；改名后旧名进别名；锁定集的剧本文本不跟着改；仍被引用的不能删。
  7. 原著对照：左侧只读显示本集对应的原文单元，两栏各自滚动，不做段落联动（默认值）；没有对应原文时开关不出现。
  8. 备注（紫色行）：作者自己看的，不渲染进 script_md，拆解、分镜和 Agent 都读不到；整集重写时跟着相邻行保留。
