# 共享画布一期：技术要点

范围和对用户的承诺以[一期方案](一期方案.md)为准。共享接口采用登录态鉴权。

| 接口（相对 `/api/v1`） | 职责 |
| --- | --- |
| `POST /canvas/:id/shares` | 所有者提交 `mode` 和 `email`；副本和转移另带 `request_key`、已确认的 `revision`。 |
| `GET /canvas/:id/shares`、`DELETE /canvas/:id/shares/:member` | 所有者列出或移除只读成员；`:member=me` 只退出自己的授权。 |
| `GET /canvas/:id/deliveries/:key` | 发送方按原请求键核对交付状态。即使转移已让原画布退役，也可在同一浏览器标签页刷新后从「个人画布」核对。查询不触发再次交付。 |
| `GET /canvas/shared`、`GET /canvas/:id/reader` | 查看者按标题搜索、分页列出授权画布，打开共享专用投影，不放宽所有者详情接口。 |
| `GET /canvas/:id/reader/media/:asset` | 查看者授权、画布有效性、引用范围和素材归属全部满足才返回媒体。列表封面使用此接口。详情中的媒体走 `GET /canvas-media/:id/:asset`，由读页签发限定路径的 HttpOnly Cookie，每次请求重新检查授权。 |

## 只读路径

`canvas_viewers` 以 `(canvas_id, user_id)` 唯一并建反向查询索引；每次查询关联未软删除且 `drama_id IS NULL` 的源画布。成员重复授权为成功；无权读取与资源不存在返回相同业务错误。共享 DTO 按允许字段构造，不直接发送整份 `payload_json`；媒体地址不得退回 `/files/` 或原存储 URL，不使用可绕过复核的公共缓存。读页复用画布渲染，不挂载作者的写入钩子或订阅作者的 WS 用户频道。

## 交付路径

1. 以 `(sender_id, request_key)` 认领一次操作，绑定画布、源版本、接收方和模式。同键同参数进行中返回处理中，已完成重放原结果；同键不同参数拒绝。重试先查交付记录，再判断源画布是否还存在，否则转移后的成功响应无法重放。
2. 校验所有者、接收账号、源版本、活跃任务与大小限制。按一致的源快照建立素材清单，验证素材归属；在数据库事务外准备受限并发的独立对象副本。清单记录临时对象与交付的关系，以便中断后清理。不可识别但涉及账号私有资源的节点不原样交付。
3. 在同一数据库事务内锁定源画布并复核版本、归属、接收账号与任务状态，写入接收方素材行、改写后的画布（新 ID、初始版本）和成功结果。仅 `transfer` 同时撤销源授权并软删除源画布。并发交付与任务启动需共用互斥检查；Agent 是独立服务，若无法可靠阻止检查后启动的新写入，须先补齐画布级交付占用机制，不能把一次“查无运行”当作转移安全保证。
4. 提交前失败则回滚数据库并清理临时对象；提交结果不明时先按请求键核实，再决定是否清理，不能误删已成功交付的对象。异常中断可通过交付记录恢复或回收，不永久占用源画布。用户主动再次发送用新键，网络重试沿用原键。

## 验证安排

后端在 `backend/internal/tests/` 覆盖授权矩阵、软删除、嵌套素材重写、幂等重放、并发转移和对象存储故障注入；前端在 `web/src/tests/` 覆盖入口、三种结果、转移确认、保存失败以及只读页面零写入。开发时先写失败测试，再跑定向测试与 `bash scripts/check.sh`。现有[短剧授权与幂等测试](../../../backend/internal/tests/repository/drama_share_test.go)可作对照，不能代替新功能的测试。
